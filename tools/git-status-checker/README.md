# Git 仓库状态看板（Git Repo Checker）

同时管理多个工作目录、批量查看其下所有 git 仓库的同步状态：哪些有未提交改动、哪些没推送、哪些落后远端，一眼看全。还能勾选多个仓库批量 `git push`。基于 Python tkinter 打包为单文件 exe，**无需安装 Python**，仅需本机装有 `git`。

![image-20261024144010394](./images/image-20261024144010394.png)

## 功能特性

- 以「组」为单位管理多个工作目录，支持 `全部` 汇总视图
- 每个仓库展示：当前分支、未提交（暂存 / 未暂存 / 未跟踪）、未推送（ahead）、未同步（behind）、无远端、分支无上游
- 可选 `git fetch` 获取准确的远端同步状态（先出本地结果，后台再刷新远端）
- 勾选多个仓库后批量 `git push`，推送完弹出逐仓库报告
- 「只看待处理」一键过滤，只看有问题的仓库
- 双击任意仓库行，直接在对应目录打开 Windows Terminal 或 Git Bash
- 零第三方依赖：仅 Python 标准库 + 本机 `git` 命令行

## 怎么用

### 1. 配置工作目录

首次打开没有任何目录，点菜单「🗂 编辑组」添加组，再点「📁 管理目录」往组里添加工作目录。程序会递归扫描这些目录（自动跳过 `node_modules`、`.venv` 等），把找到的 git 仓库列进表格。

- 一个目录如果本身是 git 仓库，直接收录，不再往下钻
- 同一组内重复添加的目录会自动去重

### 2. 查看状态

点「⟳ 刷新」扫描全部组。表格先显示本地扫描结果（未提交等），后台 fetch 完成后自动更新远端状态（未推送 / 未同步）。期间无问题的仓库显示「检查远端…」。

| 状态   | 含义                                       | 行底色 |
| ------ | ------------------------------------------ | ------ |
| 错误   | git status 解析失败 / 超时                 | 浅红   |
| 待处理 | 有未提交、无远端、无上游、未推送或未同步   | 浅橙   |
| 正常   | 干净且与远端同步                           | 白 / 斑马纹 |

「详情」列给出具体条目，例如 `未提交 3；未推送 2`。

### 3. 批量推送

勾选要推送的仓库（支持「☑ 全选」），点「⬆ 推送勾选」，确认后逐个执行 `git push`，完成后弹出 `✔/✘` 报告并自动刷新。

> 推送不带 `--set-upstream`：分支无上游或仓库无远端时推送会失败，需先在仓库里手动建立上游。

### 4. 快捷打开终端

双击任意仓库行，在该仓库目录打开终端。默认 `auto`：优先 Windows Terminal，未安装则用 Git Bash；可在「⚙️ 设置」里改为强制 `wt` 或 `gitbash`。

## 配置文件

配置持久化在用户主目录 `~/.git-repo-checker.json`：

```json
{
  "groups": {
    "默认": ["E:\\work\\a", "E:\\work\\b"]
  },
  "prefs": {
    "terminal": "auto"
  }
}
```

可通过菜单「📝 配置文件」直接打开编辑。注意：**外部修改后不会自动重载，需重启程序生效**。

## 已知限制

- 外部编辑配置文件后需重启程序才会生效
- 切换组只过滤显示上次刷新的数据，不会自动重新扫描
- fetch 阶段受网络限制，仓库越多后台刷新越久（16 并发、单仓库 15s 超时）
- 工作目录本身是仓库时不扫描其内部嵌套仓库
- 扫描开始后无法取消
- 打开终端功能面向 Windows（`wt` / Git for Windows 的 `bash`）
