# awesome-beehive-insight-tools

beehive-insight 组织下的开源工具集合。

## 工具列表

### [file2markdown](./file2markdown)

基于 [microsoft/markitdown](https://github.com/microsoft/markitdown) 的文档转 Markdown 工具，支持批量转换与图片提取。

- 支持 Word / PDF / PPTX / XLSX / HTML / 图片 / 音视频 / 文本 / 电子书 / ZIP / 邮件 等格式
- 自动从 `.docx` 提取图片，按文档真实顺序命名
- 单 exe 同时支持 GUI 与 CLI
- GUI 多任务队列，每任务可独立开始 / 停止 / 删除

→ 详细文档：[中文](./file2markdown/readme.md) · [English](./file2markdown/readme.en.md)
