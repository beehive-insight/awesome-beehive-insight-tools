# awesome-beehive-insight-tools

A curated list of open-source tools maintained by the beehive-insight organization.

## Tools

### [file2markdown](./file2markdown)

A document-to-Markdown converter built on top of [microsoft/markitdown](https://github.com/microsoft/markitdown), with batch conversion and image extraction.

- Supports Word / PDF / PPTX / XLSX / HTML / images / audio / video / text / ebooks / ZIP / email, and more
- Automatically extracts images out of `.docx`, named by their real order in the document
- A single exe supports both GUI and CLI
- The GUI runs a multi-task queue; each task can be started, stopped, and deleted independently

→ Docs: [English](./file2markdown/readme.en.md) · [中文](./file2markdown/readme.md)
